## 📝 Quick Command Summary

If you're using Terminal (from your project directory):

```bash
# 1. Initialize git (if not already done)
git init

# 2. Add all files
git add .

# 3. Make first commit
git commit -m "🎉 Initial commit - Solomine v1.0"

# 4. Add GitHub remote (after creating repo on GitHub.com)
git remote add origin https://github.com/YOUR_USERNAME/solomine.git

# 5. Push to GitHub
git branch -M main
git push -u origin main
```

**That's it!** Your project will be on GitHub! 🎉

## 🛡️ Security Reminders

Before pushing to GitHub, make sure:

- [ ] No API keys in code (check `Config.swift`)
- [ ] No passwords or secrets
- [ ] No personal data
- [ ] No large files (>100MB)
- [ ] `.gitignore` is working

If you accidentally commit a secret:
1. Remove it from code
2. Change/revoke the secret
3. Force push: `git push --force`
4. Or make repo private temporarily

## 💡 Pro Tips

### Make Your Repo Stand Out

1. **Add a Banner Image**
   - Create 1280x640px image
   - Upload in GitHub Settings → Social Preview
   - Shows when people share your link

2. **Add Screenshots**
   - Take 4-5 app screenshots
   - Add to README in a nice grid
   - First impression matters!

3. **Write a Good Description**
   - Keep it short (1-2 sentences)
   - Include key technologies
   - Example: "iOS marketplace connecting builders with clients - Built with Swift & SwiftUI"

4. **Use Emojis**
   - Makes README more engaging
   - Use sparingly and meaningfully
   - Already included in templates!

5. **Keep README Updated**
   - Update when adding features
   - Keep screenshots current
   - Document breaking changes

### Git Workflow Tips

1. **Commit Often**
   - Small, focused commits
   - Clear commit messages
   - Easy to track changes

2. **Use Branches**
   - `main` for stable code
   - `feature/*` for new work
   - Merge when ready

3. **Pull Before Push**
   - Always `git pull` first
   - Prevents conflicts
   - Keeps you in sync

4. **Review Before Committing**
   - Check `git status`
   - Review `git diff`
   - No unwanted files
