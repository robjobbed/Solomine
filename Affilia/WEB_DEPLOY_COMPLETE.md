## 🚀 Deploy in 3 Commands

### Automated Deploy (Easiest)

```bash
# From your Solomine project root
chmod +x deploy-web.sh
./deploy-web.sh
```

This script will:
1. ✅ Add web files to git
2. ✅ Commit changes
3. ✅ Push to GitHub
4. ✅ Install dependencies
5. ✅ Test build
6. ✅ Deploy to Vercel

**Total time: 2 minutes!**

### Manual Deploy (Also Easy)

```bash
# 1. Push to GitHub
git add web/
git commit -m "🌐 Add web version"
git push origin main

# 2. Deploy to Vercel
cd web
npm install
npm run build
vercel --prod
```

### Dashboard Deploy (Easiest for First Time)

1. Push to GitHub:
   ```bash
   git add web/
   git commit -m "🌐 Add web version"
   git push origin main
   ```

2. Go to https://vercel.com/new

3. Import your repo: **robjobbed/Solomine**

4. Configure:
   - Root Directory: **web**
   - Framework: Next.js (auto-detected)

5. Click **Deploy**

6. Done! Live in 30 seconds! 🎉
